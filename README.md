## Descripción del proyecto
Proyecto de análisis de datos de ventas de Global E-commerce, desarrollado como trabajo final.

El objetivo es analizar el comportamiento comercial, identificar tendencias de ventas y generar información útil para la toma de decisiones.

## Herramientas utilizadas
- **SQL Server:** consultas y extracción de información.
- **Power BI:** modelado de datos, creación de medidas DAX y dashboard interactivo.
- **Excel / CSV:** dataset utilizado para el análisis.

## Contenido del repositorio
- `SQL/`: consultas SQL desarrolladas.
- `Power BI/`: archivo del dashboard (.pbix).
- `Dataset/`: conjunto de datos original.
- `Informe final/`: documento PDF con el desarrollo del proyecto, análisis y conclusiones.

## Principales análisis
- Evolución mensual de ventas.
- Ventas por categoría de producto.
- Indicadores comerciales: ventas totales, cantidad de operaciones, ganancia y ticket promedio.
- Análisis estadístico de los importes de venta.
